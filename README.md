# NeuroStudy 🧠

NeuroStudy is an AI-powered learning platform designed to help students create personalized study plans and organize their learning in one place.

Students can select one or multiple subjects and specify what they want to study. The platform uses AI to generate a personalized learning plan and presents it through an interactive dashboard.

### Key Features

* 🤖 AI-powered personalized study plans
* 📚 Multiple subject selection
* 📊 Interactive student dashboard
* 🎯 Topic-based learning goals
* 📝 Personalized study recommendations
* 📈 Study progress tracking

### Goal

The goal of NeuroStudy is to make studying more **personalized, organized, and efficient** by combining AI with a student-focused learning dashboard.

### Tech Stack

* Frontend: React.js
* Backend: Node.js, Express.js
* Database: MongoDB
* AI: AI/LLM API
